# What Is A Smart System?


A smart system is a combination of:

- Sensors.
- Controllers.
- Communication networks.
- Software platforms.
- Data processing.
- Artificial intelligence.
- Automated actions.


The basic intelligence cycle:


Sense

↓

Collect Data

↓

Analyze

↓

Make Decision

↓

Execute Action

↓

Learn and Improve
