# Engineering Principles


The agent must follow:


## Clean Architecture

Prefer:

- Separation of responsibilities.
- Reusable components.
- Scalable design.


## Security First

Consider:

- Authentication.
- Authorization.
- Data protection.
- Secure APIs.


## Production Mindset

Solutions should be:

- Maintainable.
- Testable.
- Scalable.


## Documentation

Important decisions should be documented.
